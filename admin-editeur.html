Astuce : tape "/" dans l'éditeur pour insérer un titre, une liste, une checklist, une citation, un encadré d'alerte, un bloc de code (thème sombre, choisis un langage pour la coloration ou "Brut"), une équation LaTeX, un tableau, un séparateur, une Image (colle une URL, elle s'affiche centrée avec une légende optionnelle) ou une Vidéo (colle un lien YouTube, elle s'intègre centrée en format responsive). Sélectionne du texte pour le mettre en gras, italique, souligné ou surligné. Tu peux aussi taper directement *gras*, _italique_, `code` ou $E=mc^2$ pour une formule en ligne (ça se convertit automatiquement dès que tu fermes la paire).
